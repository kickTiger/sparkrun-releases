## About SparkRun

SparkRun is a desktop app for quickly capturing ideas and organizing them later. Visit the [official website](https://sparkrun.net/) for product information.

This repository is the official download and update channel for SparkRun. It does not contain the application's source code or build system.

<!-- section:downloads -->

## Downloads

Download the newest installer from the [latest release](https://github.com/kickTiger/sparkrun-releases/releases/latest).

Current macOS builds are not notarized with an Apple Developer ID. macOS may require you to explicitly allow the app the first time you open it.

<!-- section:updates -->

## App updates

SparkRun can check for updates from this repository. Update metadata is verified by the app before an update is installed.
