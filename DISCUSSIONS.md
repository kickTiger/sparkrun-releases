# Discussions Setup

Recommended discussion categories for `sparkrun-releases`:

- Announcements
- Questions
- Ideas
- Roadmap
- Show and tell

Guidance:

- Use Issues for reproducible bugs and upgrade failures.
- Use Discussions for general questions, workflow ideas, and product feedback that is not yet actionable.
- Convert a Discussion to an Issue only when it becomes a concrete, reproducible, or planned work item.
