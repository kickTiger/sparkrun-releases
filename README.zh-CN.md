## 关于 SparkRun

SparkRun 是一款用于快速捕获想法并在之后进行整理的桌面应用。产品信息请访问[官方网站](https://sparkrun.net/)。

本仓库是 SparkRun 的官方下载与更新渠道，不包含应用源代码或构建系统。

<!-- section:downloads -->

## 下载

请从[最新版本页面](https://github.com/kickTiger/sparkrun-releases/releases/latest)下载安装包。

当前 macOS 版本尚未使用 Apple Developer ID 完成公证。首次打开时，macOS 可能要求你明确允许运行本应用。

<!-- section:updates -->

## 应用更新

SparkRun 可以从本仓库检查更新。安装更新前，应用会验证更新元数据。
